### 1.2 处方调剂差错（痛点量化数据，BP 必须用）

- **三级 / 二级医院系统综述**（13 篇中文文献荟萃）：质量改进前**门诊药房调配差错率中位数 5.1‰**，改进后 1.1‰
- 差错构成：**审方错 34.3%、调剂错 55.2%、发药错 10.4%**
- 主因：人员疲劳、工作量大、惯性思维
- 来源：[《药学实践杂志》2021](https://yxsj.smmu.edu.cn/cn/article/doi/10.12206/j.issn.1006-0111.202105091)
- 国家共识：[《中国用药错误管理专家共识》](https://www.cmt.com.cn/show/index/2727)

**写 BP 用**：「医院药房调配差错率 5.1‰，即每分装 1000 张处方有 5 张出错；按 1 张错发药均处理成本 1 万元算……」

### 3.3 智慧医院评级链路

- 国家卫健委"**三位一体**"智慧医院评估：
  - 智慧医疗（电子病历）
  - 智慧服务
  - 智慧管理
- 外加 **医院信息互联互通成熟度测评**（7 级：一级 → 五甲）
- 智慧服务评级中**药事服务**为强制评估，自动化发药 / 智能药柜可计分
- [卫健委 / HIT 专家网](https://www.hit180.com/35422.html) / [CHIMA](https://www.chima.org.cn/Html/News/Articles/17073.html)

**结论**：医院上 4 级以上评级是采购自动药房设备的强驱动力——评委追问"医院为什么要买"时这条直接答。

### 3.4 医疗器械分类与认证路径

- 现行《医疗器械分类目录》依据 2023 年药监局公告 [101 号](https://yjj.sh.gov.cn/qtgzwj/20230817/37eb9957a8214777800b71c3415da91f.html)
- **自动发药机 / 智能药柜在中国按 II 类医疗器械管理**（健麾、艾隆均走此路径）
- 省级药监局审批，**周期 12-18 个月**
- 如系统加上"处方前置审核 AI"模块，AI 模块可能单独需要 **AI 医疗器械 III 类证**

**我们的对策**：
- MVP / 试点阶段：定位「**药品搬运 / 仓储辅助设备**」，**不接触人体 / 不参与诊疗决策** → 非医疗器械
- 量产阶段：II 类注册（参考 [CIRS](https://www.cirs-group.com/cn/md/chan-pin-fen-lei-jie-ding-ji-zhu-ce-ce-lve)）

### 3.5 互联网+ 评分加分的"国家战略对接"路线

按好讲程度排序：

1. **🥇 健康中国 2030 + AI+医疗 2025（最稳）** —— 直接命中"智慧药房"和"处方核对"政策原文关键词
2. **🥈 乡村振兴 / 基层医疗** —— [2023 年中办国办文件](https://www.gov.cn/zhengce/2023-02/23/content_5742938.htm)明确"互联网+医疗、智能辅助"作为乡村医疗赋能手段；我们的低成本机械臂下沉到乡镇卫生院 / 社区药店，故事性强
3. **🥉 积极应对人口老龄化** —— 3.1 亿老年人 + 处方量激增天然论据

**推荐**：主轴走 1，副轴讲 2、3 作为支撑——**三轴交织 = 满分社会价值章节**

## 四、最终的关键判断

### 4.1 我们和谁最像、差异在哪

- **业务侧最像** ：健麾 / 艾隆（处方调剂自动化）
- **技术侧最像** ：Tecan / 镁伽（机械臂 + 视觉 + AI）

**三大差异化**：
1. **形态差异**：竞品 = 百万级 + 密集货柜 + 滑道封闭式；我们 = 10 万级 + 开放工作单元 + 6DOF 机械臂 → **柔性、可改造、能放进社区药店**
2. **场景差异**：竞品 = 按瓶 / 按盒发药；我们 = **单剂量患者分装**（PillPick 的国内平替）→ 命中老龄化"按次定量、按日定量"刚需
3. **拓展性差异**：同一套软件栈一键迁移到**实验室器材分拣** → "医疗+科研双场景"故事 = 估值拉宽

### 4.2 进入门槛评估

| 维度 | 门槛 | 说明 |
|---|---|---|
| 医疗器械资质 | **中**（II 类居多）| 12-18 月；建议先按"非接触搬运设备"切入规避 |
| 渠道资质 | **高** | 医院需 GSP / HIT 集成商资质 / 招投标；**社区药店明显更易突破** |
| 技术门槛 | **中** | 6DOF + ROS + 视觉算法开源生态成熟；难点在**药品 SKU 库构建 + HIS 接口** |
| 资金 | **中** | 单台 BOM 3-8 万；启动期 200-500 万样机 + 认证（待核实精确数） |

**核心壁垒**：不在硬件，而在 **药品 SKU 数据 + 医院系统接口 + 认证路径**。学生团队主打**"机械臂 + 视觉算法 + 药品识别数据集"为核心 IP**。

### 4.3 一句话推介故事（直接进 PPT 收尾页）

> 「我国 60 岁以上人口 **3.1 亿**、零售药店 **68 万家**、医院年处方 **100+ 亿张**，而药房自动化**院端渗透率仅 18.9%**、**零售端仅 0.5%**。健麾、艾隆等头部厂商单台百万级，只能服务三甲。我们用 6DOF 机械臂 + 视觉 AI 把单台成本压到 **10 万元量级**，直接落地**健康中国 2030**「发展智慧药房」与**2025 年五部门 AI+医疗实施意见**「推广处方调剂、药品核对智能应用」的政策红线，下沉**乡村振兴**所要求的基层医疗能力建设。**我们不是和健麾竞争三甲，而是开辟社区+县乡的下沉增量市场。**」

**这一段命中**：老龄化痛点 + 数字鸿沟 + 国产替代 + 健康中国 2030 + AI+医疗 2025 + 乡村振兴——**六个国家战略一次性串起来**。
