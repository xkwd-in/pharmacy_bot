# 02 痛点与价值主张

> 用途：写 BP「第一章 1.1 项目背景与痛点」、PPT「P2 问题 / P3 方案」
> 这是评委最先看的部分，痛点不够痛、价值不够痛快，后面全废。

---

## 一、痛点全景（4 大场景）

### 场景 1：医院门诊药房（核心场景）

**真实痛点**：
- 门诊高峰时段（上午 8:30-11:30），单窗口药师每小时调剂处方 60-120 张，错误率约 0.06-0.5%（即 **每天可能错发 1-3 张处方**）
- 错发药事件后续处理成本（投诉、医患纠纷、行政处罚）单次 5000-50000 元
- 药师培训周期 1-3 年，离职率高（夜班、薪酬限制），招人难
- 药品摆放靠记忆+经验，新员工出错率高
- 处方 + 患者 + 药品三方核对耗时长，限制窗口吞吐量

**关键数字（待核实，标【待】是建议团队找出处补充的）**：
- 全国二级以上医院数 **约 1.2 万家**（【待】卫健委 2023 年统计公报）
- 单院年门诊处方量 **30 万 - 500 万张**（按医院级别）
- 药剂师人均年薪 **8-15 万**（医院药房）
- 单院药房年人力成本 **150-800 万**

### 场景 2：社区药店 / 连锁药店

**痛点**：
- 单店通常 1-2 名药师驻店，无法 7×24 营业
- 处方药销售合规要求严（执业药师审核电子处方）→ 远程审方 + 现场无药师场景下无法发药
- 老年顾客找药慢、药师讲解时间长，单笔成交时间长
- 进销存依赖纸质 / 简单 ERP，库存不准

**关键数字（待核实）**：
- 全国零售药店数 **约 65 万家**（【待】2023 年药店行业白皮书）
- 连锁化率 **约 58%**（益丰、大参林、老百姓、一心堂等头部连锁）
- 单店日均处方流转 **30-200 张**

### 场景 3：养老机构

**痛点**：
- 失能 / 半失能老人多药并用：人均日服药品种 **5-12 种**（多病共患）
- 护工分药差错率高（无专业药学培训，错发漏发常见）
- 慢性病药品库存管理混乱，部分药品过期未发现

**关键数字（待核实）**：
- 全国养老机构数 **约 4 万家**（民政部 2023）
- 床位总数 **约 820 万**
- 65 岁以上人口 **2.1 亿+**，慢病服药老人占比 **75%+**

### 场景 4：临床试验 / 科研 / 中心药房

**痛点**：
- 临床试验药品双盲分发对**剂量准确性**和**患者匹配**要求极高
- 科研机构样品 / 试剂分拣依赖人工，易污染、易错
- GCP / GMP 要求**全流程可追溯**——目前靠手写记录 + 二次录入

**关键数字（待核实）**：
- 全国 CRO / SMO 公司 **约 5000 家**
- 一类新药临床试验单年新立项 **2000+**

### 场景 5（拓展）：实验室器材分类

**痛点**：
- 生物 / 化学 / 物理实验室耗材种类多、形状杂
- 学生 / 助理人工分拣效率低、易混
- 危险品 / 易碎品需要规范化管理

> 💡 这个场景**比赛角度放在「未来拓展」**比较好，主线还是医疗——医疗故事更性感、政策对接更直接。

## 二、价值主张（每个角色一句话能记住）

### 对患者
"**少等 10 分钟，零错发药**"——24h 无差错智能取药。

### 对医院 / 药店老板
"**1 台机器 = 0.7 个药师 × 24h × 0 招聘成本 × 0 离职率**"
- 12-18 个月回本（按替代 1 个夜班药师 + 减少 80% 错发损失计算）
- 7×24 运转，夜班 / 节假日不停工

### 对药剂师本人
"**把你从机械分拣里解放出来，专心做处方审核和患者咨询**"
- 不是抢饭碗，是升级岗位（这话术对采购决策链很重要——药剂科主任是决策人之一）

### 对医院管理者
"**全流程可追溯 + HIS 自动审计 + 应对评审加分**"
- 互联互通成熟度评级、智慧医院评级、JCI 评审对自动化的明确鼓励条款

## 三、价值量化（关键数据，可直接进 BP）

### 错发药降本

假设一家二级综合医院：
- 日处方量：3000 张
- 错发率：人工 0.06%（高位估算）→ 机器 0.005%
- 单次错发处理成本：1 万元
- **年节省错发损失**：3000 × 365 × (0.0006 - 0.00005) × 10000 ≈ **60.2 万元/年**

### 人力成本替代

替代 1 名夜班药师 + 减轻 1 名白班药师约 60% 工作量：
- 夜班药师年薪 + 五险一金 ≈ 12 万
- 白班药师 60% 工时折合 ≈ 8.4 万
- **年节省人力成本**：**约 20 万元/年**

### 24h 运营增收

社区药店延长营业时间到 24h，夜间客单（急性病、儿童发烧、外卖配送等）：
- 假设单店夜间增收 200 元/天 × 365 天 = **7.3 万元/年增收**

### 综合回收期

- 设备售价（目标）**18-25 万 / 台**
- 单院年综合收益（节省 + 增收）**约 25-90 万**（按场景规模）
- **回收期 6-18 个月**（这个数字评委会反复问，要写得有依据）

## 四、痛点 → 我们方案的对应关系（写 PPT P2-P3 用）

| 痛点 | 现有方案 | 我们的解法 |
|---|---|---|
| 错发药 | 双人复核（人力成本翻倍）| 双通道视觉识别，准确率 99.5%+ |
| 招人难 | 提高薪酬 / 接受人手不足 | 替代重复劳动，留药师做高价值工作 |
| 夜班空缺 | 关门 / 派班 | 7×24 自动运行 + 远程审方 |
| 库存对账 | 月度盘点 + 手工核对 | 实时联动，扫码即扣减 |
| 处方追溯 | 纸质 + ERP 二次录入 | 全流程数字化，HIS 自动同步 |
| 多药老人分药 | 家属 / 护工凭记忆 | 按患者日剂量自动分包 |
| 临床试验双盲 | 专人双签 + 纸质记录 | 患者 ID + 药品 ID 数字闭环 |

## 五、社会效益叙事（互联网+ 加分点，必写）

互联网+ 评分有「社会价值」隐性维度，建议从 3 个角度切入：

1. **健康公平** —— 让县域 / 乡镇 / 偏远地区也能 7×24 取药，缓解基层药学服务紧缺
2. **老龄化应对** —— 针对失能老人多药共服场景，降低家庭 / 养老机构照护负担
3. **国产替代** —— 当前医院药房自动化设备 80%+ 进口（Swisslog、Omnicell），单台进口设备 200-800 万；我们目标 20-30 万，可推广到中小医院和乡镇
