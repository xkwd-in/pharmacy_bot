# 03 风险与短板（含答辩 Q&A 预演）

> 用途：写 BP「第四章 4.4 风险与应对」、PPT「P11 进度与里程碑 + 风险章节」
> 更重要：**评委追问环节** 的标准答案预演。学生项目最容易被打爆的就是「你这个不行 / 你这个做不出来」。
>
> 原则：**主动暴露 + 给方案 > 被动回避**。评委追问时一旦答不上，全场气氛就垮。先列硬伤，再给应对，姿态远比硬伤本身重要。

## 一、技术短板（来自真实代码审计）

### 短板 1：机械臂工作范围只有 18 × 8 cm

**事实**（写 BP 不要写这条，写 Q&A 用）：
- 现有套件工作空间 x ∈ [-0.11, 0.07] m，y ∈ [0.165, 0.24] m
- 约 18 × 8 cm，远小于商用药房自动化设备（Swisslog PillPick 工作面 60 × 100 cm+）

**应对**（写 BP「产品路线」章节用）：
1. **MVP 阶段**：单格 6-8 cm 的药盒分拣，工作面恰好可容纳 6-9 格，**够用**
2. **量产 v2**：接入套件自带的 **滑轨扩展（13.JetArm 机械臂+滑轨结合课程）**，工作面扩到 100 × 30 cm
3. **量产 v3**：选型升级到中型协作臂（UR3 / Franka / 国产节卡 / 大族），工作面 60 cm 半径

**评委追问应答**：
> 「我们 MVP 验证业务逻辑，量产时硬件不是瓶颈——市面上 5-15 万的协作臂方案成熟，我们的核心壁垒在软件层。」

### 短板 2：夹爪无力反馈，抓不抓得稳"全凭信仰"

**事实**：现有夹爪开合角度硬编码（pre_grasp=350, grasp=570），**没有力 / 电流 / 触觉传感**。对软包装、胶囊、小药片不可靠。

**应对**：
1. **MVP 阶段**：限定分拣**已包装药盒**（最常见的硬纸盒装），夹爪角度调参足够
2. **v1.5**：加舵机**电流采样**反馈（套件 STM32 已有 ADC，软件改造即可），实现简易抓握判断
3. **v2**：换装**柔性指尖 + 力传感器**（市价 1000-3000 元，国产 + 进口可选）
4. **v3 / 复杂场景**：吸盘式端拾器替代（适合泡罩 / 软包装）

**评委追问应答**：
> 「医疗场景 90% 是硬纸盒装，MVP 完全够用；进阶场景的力反馈我们 v1.5 用舵机电流采样实现，加传感器后期硬件成本上浮 1000 元以内。」

### 短板 3：相机 640×480 分辨率对条码识别勉强

**事实**：套件用 GEMINI RGBD 相机，640×480 是默认输出。条码扫描在画面占比 < 10% 时识别率明显下降。

**应对**：
1. 升级相机驱动到 1280×720（同款硬件支持，改配置即可）
2. 加**辅助识别相机**（单独一颗专用条码扫描相机，红外补光，几十元）
3. 算法层做**ROI 自动放大 + 多帧融合**降低单帧依赖

**评委追问应答**：
> 「分辨率不是硬件限制，软件配置就能升到 1080P；最坏情况加一颗 80 元的条码专用相机彻底解决。」

## 二、业务 / 商业风险

### 风险 1：医疗器械准入门槛（最容易被打的问题）

**核心问题**：药房分拣机械臂**是不是医疗器械**？需要哪类注册？

**目前判断（建议团队向当地药监咨询确认）**：
- 若设备仅完成**药品物理分拣**（不接触人体、不影响药品本身性质），通常归为 **「药品仓储/物流自动化设备」**，**非医疗器械** → 无需医疗器械注册证
- 若涉及**剂量分割、片剂切割、注射剂配制** → 可能归入 II 类医疗器械（需注册证、临床试验或免临床通道）
- 若设备数据进入**电子处方流转**、参与诊疗决策 → 可能涉及医疗软件 II 类（电子处方流转管理软件）

**应对**：
1. **MVP 与 BP 阶段**：定位为**药房仓储/调剂辅助设备**，明确**不参与药品制造和剂量分割**，规避注册门槛
2. **试点阶段**：通过医院药剂科以「内部使用工具」名义部署，类似条码枪、自动柜
3. **量产阶段**：申请 II 类注册（如必要），周期 12-24 个月，预算 30-100 万

**评委追问应答**：
> 「我们定位为药房调剂辅助工具，参照条码枪 / 自动药柜 / RFID 货架的监管路径，无需医疗器械注册；进入临床流程后按需办理 II 类，时间和预算都已规划。」

### 风险 2：客户决策链长、采购周期慢

**事实**：医院药房采购涉及：药剂科主任 → 信息科 → 设备处 → 采购处 → 主管院长。
- 决策周期 **6-18 个月**
- 单院预算审批可能跨财年
- 招投标流程对学生团队是门槛

**应对**：
1. **从 KOL 开始**：先打 1-2 家三甲药剂科主任（学校校友资源 / 导师资源）
2. **借势经销商**：医疗器械经销商渠道成熟，分销让利 20-30% 换取渠道资源
3. **政府采购路径**：智慧医院 / 智慧药房专项资金 / 国债项目（每年若干批次）
4. **轻量级试点**：先卖**单台试用 + 半年免费**，把数据攒出来再签长合同

**评委追问应答**：
> 「我们不直接 toB 医院端推销，而是通过 [导师/校友/合作医院] 资源进入 1-2 家三甲试点，跑通后通过 [经销商网络/政府采购] 规模化推广。」

### 风险 3：竞品大、巨头压制

**潜在巨头**：Swisslog (中国)、Omnicell、ScriptPro；国内远大医药信息化、深圳普门、北京艾力斯。

**应对**：
1. **错位竞争**：巨头瞄准三甲大医院（单价 200-800 万 / 套），我们瞄准**二级以下 + 社区 + 养老**（单价 20-30 万）
2. **国产化政策窗口**：医疗设备国产替代是明确国家方向（《医疗装备产业发展规划 2021-2025》）
3. **场景细分**：处方分装 / 患者分包 / 库存联动**多模式可切换**，巨头方案大多单一场景

**评委追问应答**：
> 「巨头服务大三甲，我们服务剩下的 80%——二级医院、社区、养老——价格带和能力带完全不同。」

### 风险 4：现金流 / 持续融资

**学生团队普遍弱点**：没钱、没量产经验、没销售团队。

**应对**：
1. 比赛阶段：**奖金 + 学校创业基金 + 导师项目分账** 撑过原型阶段
2. 天使轮（毕业前后）：50-200 万，估值 500-1500 万，主要靠**导师推荐 / 高校创投基金 / 当地科技局**
3. A 轮：1500-3000 万，估值 5000 万-1 亿，需要**已签约客户数据**
4. **保底方案**：被现有医疗信息化企业**收购或战略合作**（远大医药信息化、东软等都有医疗机器人布局意愿）

## 三、团队短板（学生团队都有）

### 短板 1：没有医疗 / 临床背景

**应对**：
- 拉**药学院 / 医学院 / 护理学院**学生进团队（互联网+ 鼓励跨学科）
- 找**临床导师**（医院药剂科主任 / 副主任医师）做技术顾问，**写进 BP 团队页**
- 列**已访谈过的医院数量**和**访谈纪要摘录**（即使是简单聊天也算调研）

### 短板 2：没有量产经验

**应对**：
- 不需要量产经验——**承认我们的角色是研发 + 算法 + 业务系统**，硬件量产合作机械臂厂商
- BP 团队页强调**软件 / 算法 / AI 能力**，硬件部分写明「外协 / 合作生产」

### 短板 3：销售经验空白

**应对**：
- 不直接做销售，**走经销商 / 渠道**
- 或者**SaaS 化软件先卖**给已经用了基础机械臂的实验室 / 医院

## 四、答辩高频问题集（≥ 30 题，让队友背熟）

### 技术类

1. **Q：你们和市面上 XX 公司比有什么区别？**
   A：见竞品对比表（在 04_市场与竞品.md 完成后填）。一句话版本：「他们做大三甲，我们做基层；他们卖硬件，我们卖软件 + 服务。」

2. **Q：识别准确率 99.5% 是怎么算的？**
   A：三路融合的理论值（条码 99% + OCR 92% + DL 模型 90%），任一成功即可，独立失败概率乘积。**MVP 阶段会做实测验证。**

3. **Q：能识别中药 / 散装药 / 注射剂吗？**
   A：MVP 不做，扫码盒装药为主；中药饮片需要不同硬件（吸盘 + 称重），列为 v3 规划。

4. **Q：处方信息泄露怎么办？数据安全？**
   A：本地化部署，处方数据不出院；接 HIS 用国密算法；通过等保三级认证（量产前）。

5. **Q：万一识别错了怎么办？**
   A：三路任一失败均触发**人工复核报警**；分拣后**二次扫码验证**；全流程视频留痕用于追溯。

6. **Q：抓不稳掉了怎么办？**
   A：（见短板 2 答辩答应）+ 落药区设软垫 + 视觉确认到位才算成功，否则重抓。

7. **Q：硬件你们自己做吗？**
   A：硬件外协（成熟方案集成），我们核心是**软件 + 算法 + 业务系统 + 与 HIS 对接能力**。

### 市场类

8. **Q：你们的客户为什么要买你们而不是 XX 大牌？**
   A：（见风险 3 答辩答应）+ 国产化 + 价格带 + 场景适配。

9. **Q：市场规模具体多少？**
   A：（02_市场与竞品.md 给出数据后填实数）。

10. **Q：你们打算怎么进入第一家客户？**
    A：导师资源 / 校友资源 / 当地三甲药剂科主任的关系入手。第一家拿试点价（成本价 + 服务费），换数据和案例。

11. **Q：客户为什么不自己做？**
    A：医院 / 药店本身没有 AI 算法和机械臂研发能力，软件 + 算法 + 集成是我们的壁垒。

### 财务类

12. **Q：成本是多少？毛利率？**
    A：（待团队建模型填实数）。预期：物料成本 5-8 万，人工 + 软件分摊 3-5 万，售价 18-25 万，毛利率 50-65%。

13. **Q：要多少钱？花在哪？**
    A：天使轮 200 万，60% 研发（AI 算法工程师 + 全栈工程师），20% 试点部署，10% 法务/认证，10% 营销/差旅。

14. **Q：什么时候盈亏平衡？**
    A：年销 30 台时综合盈亏平衡（假设毛利 50% × 25 万 × 30 = 375 万 ≈ 团队全年成本）。

15. **Q：估值依据？**
    A：医疗 AI / 医疗机器人种子轮估值 P/S 不适用，按**愿景估值法**：3 年内 100 台部署、单台年服务费 5 万、总年收入 500 万——按 SaaS 10x P/S 估 5000 万；当前阶段给 20-25% 折扣 = 1000-1500 万。

    A：（待团队填实）。

17. **Q：导师 / 顾问介绍一下？**

23. **Q：被巨头收购了你们怎么办？**
    A：被收购也是不错的退出路径（团队成员认可）；如果不被收购则继续独立做基层市场。

## 五、最容易翻车的 3 个点（团队必须背熟）

1. **「错发率 0.06%」这种数字必须有真实出处，不能想当然** —— 用药差错相关论文必查
2. **「医疗器械注册」绝对不能撞枪口** —— 一句「我们不是医疗器械，是仓储设备」必须答得自信
3. **「我们和 XX 公司有什么不同」答不上来就完了** —— 竞品对比矩阵表必须背到滚瓜烂熟

> 队友答辩前**至少模拟 3 次**，每次换不同队员上去答，直到所有人能 5 秒内回答任意一题。
