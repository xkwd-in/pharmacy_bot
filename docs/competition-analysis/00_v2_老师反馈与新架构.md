## 二、🚨 法律红线（最重要！BP / PPT 通篇遵守）

| 错的说法（会被淘汰） | 对的说法（合规且加分） |
|---|---|
| ❌ AI 看病诊断 | ✅ **AI 辅助症状归类**（输出建议，不下结论） |
| ❌ AI 开处方 | ✅ **AI 处方前置审核**（辅助医师/药师） |
| ❌ AI 推荐药品 | ✅ **OTC 智能选购指导**（仅非处方药） |
| ❌ 替代药师 | ✅ **智能药师助手**（人类按确认才执行） |
| ❌ 自动调剂发药 | ✅ **辅助调剂**（药师 review 后调剂） |

### 法规依据
- 《医师法》第 14 条：仅医师可诊疗
- 《互联网诊疗管理办法》第 14 条：禁止 AI 自动开方
- 《药品经营质量管理规范》：调配药品必须由药师签字
- ✅ **2025-11-04 五部门《意见》**：明确鼓励"**处方前置审核**等智能应用"——我们的合规切口

### 操作原则
**AI 给建议 → 人类药师/医师 1 秒钟点确认 → 机械臂执行**

这条"确认按钮"是合规命门，所有演示、BP、PPT、代码都必须体现。

## 五、4 大技术创新点（BP 第六章 / PPT 第 8-9 张直用）

### 创新点 1：**三模态视觉融合**（业内罕见组合）
- 单 pyzbar 99% / 单 OCR 92% / 单 YOLO 90% → 投票融合 **99.5%+**
- 解决"药盒条码磨损、OCR 反光、DL 同款不同批次"三类失败 case
- 业界对标：ScriptPro SP200 **99.7%**（仅条码单路）

### 创新点 2：**AI 处方前置审核闭环**
- 政策直接对应：2025-11-04 五部门《意见》原文
- LLM + RAG（药典 + 配伍禁忌表）做配伍冲突检测
- 准确率目标：药物相互作用召回率 95%+

### 创新点 3：**4 种调度模式**
- 模式 A 品类分装（常规库存补仓）
- 模式 B 处方分装（按医嘱抓取）
- 模式 C 患者分装（一人一袋，居家养老场景）
- 模式 D 库存补仓（自动盘点 + 补货）

### 创新点 4：**离线优先 + 渐进上云**
- 整套系统断网可跑（LLM 本地 7B、ASR 离线、OCR 离线）
- 上云仅做：处方同步、补仓单推送、报表汇总
- 解决基层医院网络差的真实痛点
