# 07 答辩 Q&A 预演（评委高频问题 + 标准答案）

> 用途：**比赛前一周每天背一遍**。评委追问环节是项目成败分水岭。
> 答题原则：**先认账 + 再给方案 + 数据收尾**。不要狡辩、不要拖泥带水、不要超过 60 秒。

---

## 第一类：技术类（最容易被打）

### Q1：你们和市面上 XX 公司比有什么区别？
**A**：「健麾、艾隆做的是**百万级密集货柜式发药机**，专为三甲；我们用 **6DOF 机械臂 + 视觉 AI**，**单台 25 万元，柔性单剂量分装**，瞄准社区药店、二级医院、养老院等头部巨头打不到的下沉市场。国外对标是 Swisslog PillPick 和 Omnicell，但他们百万美金级，进口无法本地化处方流。」

### Q2：识别准确率 99.5% 怎么算的？
**A**：「三路融合的理论值——**条码 pyzbar 单路 99%，OCR PaddleOCR 单路 92%，自训练 YOLO 视觉模型 90%**，三路任一成功即可，独立失败概率乘积 ≈ 0.0007%。MVP 阶段会做 1000 次实测验证。对标 ScriptPro 商用机器人 99.7%。」

### Q3：能识别中药 / 散装药 / 注射剂吗？
**A**：「MVP 不做，**先聚焦盒装西药 / OTC**（占处方量 80%+）；中药饮片需要不同硬件（吸盘 + 称重），列入 v3 规划；注射剂需要 GMP 级洁净环境，是 v4 远期规划——我们不通吃，先打透一个场景。」

### Q4：处方信息泄露怎么办？数据安全？
**A**：「**本地化部署 + 国密算法 + 等保三级认证**。处方数据不出医院本地服务器，与 HIS 内网对接，符合卫健委 2018《国家健康医疗大数据标准、安全和服务管理办法》。」

### Q5：万一识别错了怎么办？
**A**：「三路任一失败都触发**人工复核报警**；分拣放置后**二次扫码验证**；全流程视频留痕用于追溯——比人工药师**有日志、有审计、有视频**三重保险。」

### Q6：抓不稳掉了怎么办？
**A**：「**MVP 限定硬纸盒药装**（占医院处方包装 90%+），夹爪角度调参足够。v1.5 加舵机电流采样实现简易力反馈，v2 换柔性指尖 + 力传感器（成本 + 1000 元以内）。落药区设软垫，视觉确认到位才算成功，否则重抓——**多重兜底**。」

### Q7：硬件你们自己做吗？
**A**：「**硬件外协**（成熟方案集成），我们核心是**软件 + 算法 + 业务系统 + 与 HIS 对接能力**——这是医院真正会持续买单的部分，也是我们的护城河。」

### Q8：工作范围只有 18×8 cm 够用吗？
**A**：「**MVP 单格 6-8 cm 药盒分拣，工作面恰好可容纳 6-9 格够用**。量产 v2 接入滑轨扩展到 100×30 cm，v3 选型升级中型协作臂（UR3 / 节卡 / 大族）到 60 cm 半径——硬件不是瓶颈，**5-15 万有大量成熟方案**。」

### Q9：相机 640×480 够吗？
**A**：「**软件配置就能升到 1280×720**（同款硬件支持），最坏情况加一颗 80 元的条码专用相机彻底解决——不是硬限制。」

### Q10：你们用的是 JetArm 教学套件？这不是教学品吗？
**A**：「**JetArm 是我们的硬件 MVP 平台，加速原型验证**——就像 Tesla 早期用 Lotus 底盘做 Roadster。我们的核心 IP 是上面的**条码 + OCR + DL 三路识别融合算法**、**处方/患者/库存业务系统**、**HIS 对接接口**——这些不存在于任何教学品里，是我们 100% 自研的。量产时硬件会换成更成熟的方案，但软件栈不变。」

## 第二类：市场类

### Q11：市场规模具体多少？
**A**：「中国自动化药房 **196.7 亿**，CAGR 持续两位数；医疗机器人 108 亿，**5 年 CAGR 25.7%**。其中**院端渗透率仅 18.9%**，对标欧美 ~80% 还有 4 倍空间；**零售端渗透率 0.5%**，是看得到天花板的蓝海。」

### Q12：为什么选择基层而不是三甲？
**A**：「**三个原因**：① 三甲被健麾艾隆吃透（CR2 = 58.7%）；② 基层增速 14.4% > 三甲；③ 头部产品百万级**基层买不起**，我们 25 万级精准卡位下沉市场。」

### Q13：你们打算怎么进入第一家客户？
**A**：「三条线并行：① 学校 / 导师资源 → 校医院或合作医院试点；② 经销商网络分销；③ 当地科技局 / 卫健委智慧医疗专项资金对接。**第一家拿试点价（成本价 + 服务费）换数据和案例**，跑通后规模化。」

### Q14：客户为什么不自己做？
**A**：「医院 / 药店没有 AI 算法和机械臂研发能力，**软件 + 算法 + 集成是我们的壁垒**。健麾、艾隆做了 20 年也只在做硬件——技术栈差异决定他们的工程师做不出我们的算法层。」

### Q15：医院采购流程那么长（6-12 个月），怎么跑通现金流？
**A**：「**两条腿走路**：① 医院端走标准采购，长周期但单价高；② **社区药店和养老院端不走招标，决策周期 1-3 个月**，可快速回款。两类客户互补，前者证明能力，后者撑现金流。」

### Q16：你们这个项目能让多少人受益？
**A**：「直接受益：**3.10 亿老人**（按医嘱按时按量服药）+ **每年 100+ 亿次诊疗的患者**（少等少错）。间接受益：**全国 5 万药剂师**（从机械分拣解放）+ **68 万家药店店主**（夜间扩营、错发减损）。**老人 + 患者 + 药师 + 老板，四类受益人覆盖。**」

## 第三类：财务类

### Q17：成本是多少？毛利率？
**A**：「单台 BOM **12-18 万**，售价 25 万，**设备毛利率 35%**；**订阅毛利率 65%+**（云平台 + 算法升级，规模化后边际成本极低）。混合毛利率 50%+。」

### Q18：要多少钱？花在哪？
**A**：「**天使轮 200 万**，分配：60% 研发（AI 算法工程师 + 全栈 + 硬件集成共 4 人）、20% 试点部署（4 个标杆点物料 + 上门服务）、10% 法务 / 认证（II 类医疗器械申报）、10% 营销 / 差旅。」

### Q19：什么时候盈亏平衡？
**A**：「**Y2 末**——按 30 台年装机 × 25 万首付 + 0.8 万月订阅 × 12 月，毛利覆盖年成本 400-500 万。**敏感性：装机量 -30% → 推迟 6 个月达到盈亏平衡。**」

### Q20：估值依据？
**A**：「**愿景估值法**——3 年累计装机 185 台、单台年订阅 12 万、Y3 ARR 2200 万；按 SaaS 10x P/S 估 2.2 亿，加上设备业务 P/S 2x 估 4000 万，**当前阶段折扣 25% = 1500-1800 万**。对标 Strateos 早期 Lab-as-a-Service 估值路径。」

### Q21：用户用了一段时间不续费怎么办？
**A**：「**核心订阅功能（HIS 对接 / 库存同步 / 算法更新 / 远程运维）锁定续费**。不续费降级为本地基础版，丢失数据看板、远程支持、安全补丁——医院 / 药店实际不敢断。参考 Omnicell 客户续费率行业基准 90%+。」

### Q22：硬件卖一次后面怎么持续赚钱？
**A**：「**四层收入结构**：硬件首付（35% 毛利）+ 软件订阅（65% 毛利）+ 耗材标签 / 备件（年 1-2 万 / 台）+ 维保增值（设备价 8-12%/年）。**对标 Omnicell：硬件已不是主收入，订阅 + 服务 + 耗材合计 50%+**。」

## 第四类：风险与认证类

### Q23：政策风险怎么看？
**A**：「**最大风险是医疗器械分类认定**。我们 MVP 阶段定位「**药品搬运 / 仓储辅助设备**」，不接触人体、不参与诊疗决策——**参照条码枪、自动药柜、RFID 货架的监管路径，无需医疗器械注册**。量产阶段如必要走 II 类（参考健麾、艾隆都是 II 类），周期 12-18 个月、预算 30-100 万，已纳入财务规划。」

### Q24：医疗器械注册要多久？
**A**：「**省级药监局审批 12-18 个月**。我们的策略是**先用「非接触搬运设备」名义切入**，等市场反馈和资金到位后启动 II 类申报——这是 **fast follower** 路径，而非 **first mover** 路径。」

### Q25：万一巨头进入这个市场怎么办？
**A**：「**三个护城河**：① **算法 IP**（条码 + OCR + DL 三路融合 + 自训练药品数据集）；② **客户绑定**（HIS 深度集成 + 续费机制）；③ **下沉渠道**（社区药店和养老院与巨头销售模型完全不匹配）。**最坏情况下被巨头收购也是合理退出**——团队认可。」

### Q26：你们这个东西过 GMP / GSP 吗？
**A**：「GMP 是药品**生产**质量管理规范，我们不生产药品；GSP 是药品**经营**质量管理规范，我们的设备**辅助药品调剂**，不直接经营药品——所以不需要我们办 GSP，**医院 / 药店本身的 GSP 资质涵盖我们的使用场景**。**我们卖的是辅助工具，不是药品流通主体**。」

### Q27：处方流转有没有合规问题？
**A**：「我们不**改变**处方内容，只是**辅助执行**——读处方 → 分装 → 复核——和药师手工流程完全等效。处方流转合规由医院的 HIS 系统负责，我们仅是其下游的执行单元。**法律责任仍在医院和药师**，我们只承担「设备故障导致的物理损坏」责任。」

## 第七类：终极一击类

### Q34：你们这个项目和 chatGPT 写一份 BP 有什么区别？
**A**：「**实物 demo + 真机代码 + 已访谈的 N 家医院的一手数据**——这是 chatGPT 给不了的。请评委看视频和代码 commit 历史。」

### Q35：你们是不是把现成套件包装一下来比赛？
**A**：「**完全相反**——JetArm 套件只解决了「机械臂能动」这个 20% 的问题；我们解决的是「机械臂能在真实药房环境工作」这个 80% 的问题——**条码识别 + OCR + 处方解析 + 患者匹配 + 库存对账 + HIS 对接** 全部自研。请看代码 diff：原始套件 N 行，我们新增 N 行。」

### Q36：你们这个项目 5 年后会变成什么？
**A**：「**3 年**：基层药房自动化龙头（年装机 150+，覆盖 200+ 县市）；**5 年**：开放平台，把视觉识别 + 机械臂 + 业务系统能力**模块化输出**给其他垂直场景（中医 / 兽医 / 化妆品分拣 / 实验室自动化）—— **从「药品分拣公司」升级为「垂直机器人 PaaS 平台」**。」

## 最容易翻车的 3 个时刻（必须特别准备）

### 翻车点 1：评委直接问出处
**应对**：「这个数据来源是 [来源]，发布于 [时间]，请允许我查一下手机记录给您准确的版本号。」**不要硬答**——查清楚比硬撑可信。

### 翻车点 2：评委质疑数据真实性
**应对**：「这是公开统计数据，[出处]。我们也做了 3 家医院的实地访谈作为一手验证——访谈纪要在 BP 附录第 X 页。」

### 翻车点 3：评委要看实物 demo 但 demo 出问题
**应对**：**事先准备 1 份兜底视频**。如果实机出问题：「设备需要 3 分钟启动，我们先看一段提前录制的 demo——这是上周在 XXX 医院的真实环境运行的。」**绝不慌**。

## 模拟答辩 SOP（队员必须执行 3 次以上）

1. **第一次**（自己人答）—— 把 36 题轮流问 5 个队员，每题限时 60 秒；不达标的现场补
2. **第二次**（导师 / 师兄答）—— 找懂这个行业的人扮评委，**故意问刁钻的衍生题**
3. **第三次**（陌生人答）—— 找完全不懂的人扮评委，**测试听得懂讲不懂的部分**

每次模拟后录视频，**回放找小动作**（眼神飘、停顿、口头禅）—— 这些细节也算分。
