## 第四章：产品与服务（3 页，约 2500 字）—— BP 最长一章

**该写什么**：4 个模块逐一展开 + 系统架构图 + 与竞品对比

### 4.1 系统总架构

直接贴 `00_v2_老师反馈与新架构.md` 的 ASCII 架构图（或队友画 Visio/draw.io 美化版）。

### 4.2 模块 ①：AI 智能药师助手

- 模型：Qwen2.5-7B-Med + LangChain + FAISS 向量库
- RAG 知识库：国家药典 + 配伍禁忌表 + 不良反应数据库
- 功能：症状辅助归类 / 用药禁忌检查 / 处方前置审核 / OTC 选购指导 / 老人用药提醒
- **合规定位**：辅助药师，不替代——药师按下确认按钮才执行

### 4.3 模块 ②：三模态视觉融合识别

| 路径 | 技术 | 单路准确率 | 速度 |
|---|---|---|---|
| 主路 | pyzbar | 99% | < 10ms |
| 辅路 | PaddleOCR PP-OCRv4 | 92% | ~ 80ms |
| 兜底 | YOLOv8s + 自标 | 90% | ~ 30ms |
| **融合** | 投票 + 置信度加权 | **99.5%+** | < 100ms |

vs ScriptPro SP200 单路 99.7% —— 我们多模态更鲁棒（破损/反光/无码场景）。

### 4.4 模块 ③：机械臂调剂执行

- 硬件：JetArm 6DOF（教学版 → 工业版量产）
- 软件：ROS Noetic + MoveIt + RRT* 避障
- 4 种调度模式（品类/处方/患者/补仓）
- 单次抓取 < 3 秒（人工 8-15 秒）

### 4.5 模块 ④：库存管理 & 智能补仓

- 实时计数 + 低位预警 + 效期监控 + 自动补仓单
- 对接 HIS：HL7 FHIR / REST API

### 4.6 与竞品对比表

| 维度 | 健麾（中国 NO.1）| 艾隆 | Omnicell（北美）| **我们** |
|---|---|---|---|---|
| 单台价格 | ~170 万 | ~100 万 | $200K+ | **20-30 万** |
| 识别方案 | 单条码 | 单条码 | 单条码 | **三模态融合** |

## 第十一章：AI 大模型合规专章（1 页，约 800 字）⭐ 老师新增模块的特别说明

**关键阐明**（每页底部都要呼应）：

1. **AI 不诊断**：仅做"症状归类"辅助，最终判定权在医师。
2. **AI 不开方**：处方权属于注册执业医师，AI 仅做前置审核。
3. **AI 推荐 = OTC 范围**：仅推荐非处方药（甲类/乙类 OTC），处方药一律不主动推荐。
4. **数据安全**：所有患者对话数据本地化存储，可选脱敏上云用于模型迭代。
5. **可追溯**：每条 AI 建议都打时间戳 + 操作员 ID，出问题可审计。
6. **可关闭**：药师可一键关闭 AI 建议，回归传统人工模式。

**政策对齐声明**：
- 《互联网诊疗管理办法》第 14 条 → 我们的"人类确认"按钮即为该条款落地
- 《生成式人工智能服务管理办法》→ 我们的 LLM 已做安全备案规划
- NMPA 关于"医用人工智能软件"分类 → 我们定位为"独立软件 + 辅助决策" SaMD
